# Stack

## Confirmed

- React `19.2.4` and React DOM `19.2.4`
- React Router `7.13.2`
- Vite `8.0.1` with `@vitejs/plugin-react`
- JavaScript and JSX; no TypeScript configuration
- ESLint `9.39.4` with the JavaScript recommended rules, React Hooks, and React Refresh plugins
- `lucide-react` for interface icons
- `nanoid` is installed but no usage was found during initial inspection
- `@vercel/og` supports generated social preview images
- Vercel-oriented rewrites and server handlers

## Commands

- `npm run dev` starts Vite development mode.
- `npm run build` creates the production bundle.
- `npm run lint` runs ESLint across the repository.
- `npm run preview` serves the built bundle locally.
