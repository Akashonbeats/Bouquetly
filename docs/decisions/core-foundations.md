# Core Foundations

## Status

Human-confirmed.

## Decisions

- Preserve Bouquetly's color system, aesthetic, and visual core.
- Layout changes are allowed when they improve the experience.
- Changes to core foundations require explicit approval.
- Existing share links must remain backward-compatible because links may already be created and in use.
- Backward compatibility must not be changed without explicit approval.

These boundaries apply alongside the experience-first engineering preference: improve the experience broadly where appropriate, but do not silently alter the protected visual foundations or invalidate historical link data.
